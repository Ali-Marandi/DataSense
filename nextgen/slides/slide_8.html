# عیب‌یابی بدون data leak

errors.jsonl
{"schema": "datasense.error/v1",
 "error_id": "e4a2b...",
 "component": "ui.import",
 "message": "Failed to load [REDACTED_PATH] for user [REDACTED_EMAIL]"}

// Telemetry: opt-in (default: false)
  • فایل datasense.jsonl رویدادهای ساختاریافته و چرخشی را به‌صورت محلی نگه می‌دارد.
  • فایل errors.jsonl خطاها را با Error ID، نام component و متن Redact شده ثبت می‌کند.
  • مسیرهای محلی و emailهای رایج در لایهٔ ثبت خطا به‌طور خودکار Redact می‌شوند؛ ارسال telemetry نیز پیش‌فرض غیرفعال است.
