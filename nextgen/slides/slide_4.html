# Data readiness قبل از تحلیل عمیق

ماژول DataReadinessInsightsModule مواردی چون missingness، identifierهای احتمالی و outlierهای IQR را به‌صورت محلی بررسی می‌کند.
امتیاز ۰ تا ۱۰۰ با آستانهٔ قابل‌تنظیم، فقط یک شاخص آمادگی است و یک تصمیم خودکار برای حذف یا تغییر داده نیست.
هشدارها تنها نام ستون و شمارش aggregate را نشان می‌دهند و هیچ‌گونه value حساس یا دادهٔ خامی را افشا نمی‌کنند.
