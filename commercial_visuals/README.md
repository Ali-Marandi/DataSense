# Commercial Visuals — Calculation Note

این پوشه نمودارهای مشتق‌شده از driverهای workbook `DATASENSE_COMMERCIAL_PLANNING_MODEL.xlsx` را نگهداری می‌کند. مقادیر با همان متغیرهای سناریویی workbook بازسازی شده‌اند، زیرا `openpyxl` فرمول‌های workbook را محاسبه نمی‌کند. این خروجی‌ها **planning scenario** هستند و پیش‌بینی تحقق‌یافته، valuation یا قیمت فهرست منتشرشده نیستند.

|---|---:|---:|---|

نمودار درآمد و EBITDA به‌صورت بصری بازبینی شدند: سه سناریو، محور سال ۲۰۲۶ تا ۲۰۳۰، مقیاس دلار و برچسب مقدار ۲۰۳۰ خوانا هستند. خط صفر در نمودار EBITDA برای تفکیک profit و burn نمایش داده شده است.

visual `pricing_tiers.png` پس از اصلاح layout بازبینی شد. واحد هر tier به‌صورت مستقل و بدون مقایسهٔ نادرست میان seat، workspace و ACV نمایش داده شده است؛ محدوده‌های ۲۹ تا ۴۹ دلار و ۳٬۰۰۰ تا ۹٬۰۰۰ دلار نیز صریحاً به‌عنوان بازهٔ آزمون درج شده‌اند.
